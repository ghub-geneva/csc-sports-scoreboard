Getting started

Anyone can view the scoreboard at csc126.cordova.gov.ph without logging in. Only this Admin page can change data, and it requires the admin email and password.

Scores are saved to a shared online database, so every phone and screen sees the same thing. The public page refreshes on its own every few seconds.

Adding a game
  1. Pick the Sport. If it has categories (Badminton, Table Tennis, Pickleball), choose them.
  2. Choose Team A and Team B (they must be different).
  3. Set the Date, and optionally the Time and Venue.
  4. Choose the Stage (see below).
  5. Leave Status as Scheduled for an upcoming game, or set it to Played to record the score now.
  6. Click Add Game.
Round robin and the finals (Stage)

Each sport category is a single round robin: every team plays each other once. Enter those games with stage Round Robin. Their results build a standings table that seeds the teams 1st to 4th (ties are broken by point difference, or set difference for set sports).

After the round robin, add two more games:

  • Championship - 1st seed vs 2nd seed. Winner is 1st place, loser is 2nd.
  • Battle for 3rd - 3rd seed vs 4th seed. Winner is 3rd place, loser is 4th.
Recording results

For a scheduled game, use the Record result box on its card in "Scheduled & Past Games", or click Edit and set Status to Played.

Volleyball and Badminton are best of 3 sets: enter each set's points (Set 1, 2, 3). Leave Set 3 blank for a 2-0. The winner is whoever takes 2 sets.

Use Reopen to move a played game back to scheduled.

Scoring and standings

Overall Standings are ranked by total points. Points come from final placement in each event:

  • 1st = 10 pts, 2nd = 7 pts, 3rd = 5 pts, 4th = 3 pts

For a sport, the Championship winner gets 10 and the runner-up 7; the Battle for 3rd winner gets 5 and the loser 3.

Special events (Muse, Banner Raising, Pinoy Games)

These are scored by placement, not by match. In Special Events Scoring, pick the event, give each team a rank (1st to 4th), and save. The same 10/7/5/3 points apply.

For Pinoy Games, type a title (e.g. Tug of War) for each game. You can add as many titled Pinoy Games as you like.

Backups and clearing data

Under Data: Export backup downloads a file with all games and events. Import backup restores from such a file (this replaces current data). Clear all deletes everything permanently. Export a backup before clearing.
